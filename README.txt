FRACTURED — TEASER WEBSITE
==========================

Built around the exact white distressed geometric logo you supplied.
The logo is stored unmodified in assets/fractured-logo.png.

TO RUN ON WINDOWS
1. Extract the ZIP file.
2. Double-click start-localhost.bat.
3. A browser opens automatically at http://localhost:3000.
   If port 3000 is busy, the server selects 3001 or 3002 instead.
4. Press Ctrl+C in the command window to stop the server.

ALTERNATIVE
Open index.html directly in your browser, or in VS Code use Live Server.

FEATURES
- Responsive homepage built in HTML, CSS and JavaScript
- Original, unchanged Fractured mark as the focal point
- Four command simulations (/warn, /poll, /clear, /remind)
- Editable simulated command parameters
- Copy-command button
- Keyboard quick navigation (Ctrl+K or Cmd+K)
- Mobile menu, scroll tracking, subtle cursor movement

IMPORTANT
This is a teaser / concept website, not a real Discord bot or dashboard.
Demo commands do not interact with Discord, store data, or send messages.
The feature list is a prospective roadmap rather than a promise of launched features.

CUSTOMISATION
- Edit website copy and content in index.html.
- Edit colours and layout in styles.css.
- Edit command previews and functionality in app.js.
- No external fonts, packages, or internet connection are required.
